# shard_i18n <small>0.3.0</small>

> Runtime, sharded, msgid-based i18n for Flutter

- No code generation required
- Sharded JSON files prevent merge conflicts
- Dynamic language switching at runtime
- CLDR plural rules for 25+ languages
- CLI tools for translation management
