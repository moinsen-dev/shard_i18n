# shard_i18n v0.4.0 Design

## Summary

Split the monolithic package into a Dart workspace with two packages, fix API defaults, and bring test coverage from 12 to ~55 tests.

## Decisions

| Question | Decision | Rationale |
|----------|----------|-----------|
| Package split approach | Dart pub workspace (monorepo) | Already used in moinsen_packages, clean separation, single repo |
| Migrator placement | Part of CLI package | It's a CLI tool, not a library. One unified executable. |
| Test scope | Core + CLI (no migrator tests) | Migrator is experimental; core and CLI affect users directly |
| Breaking changes | Structure + small fixes | No API breaks, just defaults and internal improvements |

## API Changes

### 1. debugLogMissingKeys default to false

```dart
// Before
bool debugLogMissingKeys = true;

// After
bool debugLogMissingKeys = false;
```

### 2. resetForTesting() method

```dart
@visibleForTesting
void resetForTesting() {
  _bootstrapped = false;
  _dict = {};
  _cache.clear();
  _loggedMissingKeys.clear();
  _supportedLocales = null;
  _assetManifest = null;
  _locale = const Locale('en');
  _pluralRules.clear();
}
```

### 3. Static RegExp compilation

```dart
static final _placeholderRegExp = RegExp(r'\{(\w+)\}');
```

### 4. Remove migrator export

`lib/shard_i18n_migrator.dart` is removed from the runtime package. Migrator code moves entirely to the CLI package.

## File Migration

```
lib/shard_i18n.dart              → packages/shard_i18n/lib/shard_i18n.dart
bin/shard_i18n_cli.dart          → packages/shard_i18n_cli/bin/shard_i18n_cli.dart
lib/cli/src/extract/             → packages/shard_i18n_cli/lib/src/extract/
bin/shard_i18n_migrator.dart     → merged into CLI as subcommands
lib/shard_i18n_migrator.dart     → removed
lib/migrator/                    → packages/shard_i18n_cli/lib/src/migrator/
test/shard_i18n_test.dart        → packages/shard_i18n/test/ (kept, extended)
```

## Unified CLI

All commands under one executable:

```bash
dart run shard_i18n_cli verify
dart run shard_i18n_cli fill --from=en --to=de --provider=openai --key=$KEY
dart run shard_i18n_cli extract
dart run shard_i18n_cli migrate lib/
dart run shard_i18n_cli analyze lib/
dart run shard_i18n_cli init
```

## Test Plan

### Core Tests (~35)

| Group | Coverage | Count |
|-------|----------|-------|
| Singleton | Instance identity | 2 |
| Bootstrap | Success, double-call, error fallback | 3 |
| setLocale | Switch, same locale, before bootstrap error | 3 |
| Translate | Simple, interpolation (single/multi/missing/null), msgid fallback | 5 |
| Plurals | en/de one/other, ru slavic, cs czech, tr turkish, fr french, custom rule | 7 |
| Fallback chain | de-DE to de to en to msgid | 3 |
| Cache | Hit, clear, after locale switch | 3 |
| String extensions | .tx, .t(), .tn() | 3 |
| Context extensions | context.t(), context.tn() | 2 |
| resetForTesting | Full reset, re-bootstrap | 2 |
| debugLogMissingKeys | Default false, activatable | 2 |

### CLI Tests (~20)

| Group | Coverage | Count |
|-------|----------|-------|
| Verify | Missing keys, extra keys, placeholder parity | 5 |
| Extract | Key detection from .t()/.tn()/.tx, JSON comparison | 8 |
| Fill | Dry-run, missing key detection (HTTP mocked) | 4 |
| Helpers | extractPlaceholders, loadLocaleTranslations | 3 |

## CHANGELOG

```markdown
## [0.4.0] - 2026-03-31

### Changed
- **BREAKING: Package split into workspace** — `shard_i18n` (runtime) and
  `shard_i18n_cli` (CLI + migrator) are now separate packages
- `debugLogMissingKeys` now defaults to `false`
- Unified CLI: migrator commands merged into `shard_i18n_cli`
  (`migrate`, `analyze`, `init` are now subcommands)
- Interpolation RegExp compiled once (minor perf improvement)

### Added
- `resetForTesting()` method for test isolation
- ~55 tests (up from 12) covering core, extensions, CLI

### Removed
- `shard_i18n_migrator` as separate executable (use `shard_i18n_cli migrate`)
- `shard_i18n_migrator.dart` library export from runtime package

### Migration from 0.3.x
- `import 'package:shard_i18n/shard_i18n.dart'` — unchanged
- CLI: `dart run shard_i18n_cli verify` (instead of `dart run shard_i18n:shard_i18n_cli verify`)
- If you used `debugLogMissingKeys`, note it now defaults to `false`
```
